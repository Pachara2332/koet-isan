# เอกสารออกแบบ: เกมจำลองชีวิตคนอีสาน (ชื่อชั่วคราว "เกิดอีสาน")

วันที่: 2026-11-17 · สถานะ: รออนุมัติ

## 1. เจตนา

เกมจำลองชีวิตบนเว็บ ผู้เล่นเกิดเป็นคนอีสานหนึ่งคน ใช้ชีวิตทีละฤดูจนสิ้นอายุ เจอเหตุการณ์จริงของภาคอีสานตามปีและจังหวัดที่อยู่ และเลือกเส้นทางชีวิตเอง ปล่อยให้คนทั่วไปเล่น

แรงบันดาลใจคือเกมแนวเดียวกับ 1in8b.life แต่เป็นงานใหม่: เนื้อหา กลไก ข้อความ และหน้าตาเขียนขึ้นเองทั้งหมด

## 2. เป้าหมาย / ไม่ใช่เป้าหมาย / สิ่งที่ถือว่าล้มเหลว

เป้าหมาย
- เหตุการณ์โลกในเกมเป็นเรื่องจริงของอีสาน มีแหล่งอ้างอิงเปิดดูได้ทุกรายการ
- ปีเกิดเลือกได้ 1970–2008 ค่าเริ่มต้น 1997 มีปุ่มลัด 1970
- เลือกเส้นทางเองทุกช่วงชีวิต: โรงเรียน ย้ายถิ่น งาน ความรัก ครอบครัว
- นิสัยตัวละครเปลี่ยนแรงกระแทกของเหตุการณ์ (คนยึดติดอกหักเจ็บหนักและนาน)
- มีเส้นทางสำเร็จรูป "เด็กโพนสวรรค์" ตามชีวิตจริงของเจ้าของโครงการ
- เล่นบนมือถือได้ดี ชีวิตหนึ่งรอบราว 30–40 นาที

ไม่ใช่เป้าหมาย (รอบนี้)
- เซิร์ฟเวอร์ บัญชีผู้ใช้ เล่นหลายคน กระดานคะแนน
- ภาษาอื่นนอกจากไทย
- ภาพวาด เสียง ดนตรี (ใช้ CSS ลวดลาย และอีโมจิเท่านั้น)
- ข้อมูลรายอำเภอครบทุกอำเภอ
- การ์ดแชร์เป็นรูปภาพ (รอบนี้มีแค่ปุ่มคัดลอกข้อความสรุปชีวิต)

สิ่งที่ถือว่าล้มเหลวแม้เกมรันได้
- ข้อเท็จจริงแต่งขึ้นแต่แสดงเป็นเรื่องจริง
- ล้อเลียน เหมารวม หรือขายความจนของคนอีสาน
- ข้อความหรือหน้าตาซ้ำกับเกมต้นแบบ
- เลือกข้างทางการเมืองในเนื้อหา

## 3. ข้อจำกัด

- เว็บสถิต: HTML + CSS + JavaScript (ES modules) ไม่มี framework ไม่มีขั้นตอน build ไม่มี dependency ตอนรัน
- ไม่เรียกเครือข่ายตอนเล่น ไม่มี analytics ข้อมูลผู้เล่นอยู่ใน localStorage เท่านั้น
- ธีมสว่างเท่านั้น
- ใช้ได้ที่จอกว้าง 360px ขึ้นไป ปุ่มกดด้วยนิ้วได้ ใช้คีย์บอร์ดได้ ตัวอักษรอ่านง่าย
- ห้ามใส่ comment ในโค้ด (กติกาของเจ้าของโครงการ)
- วันเกิดเต็มและชื่อหมู่บ้านของเจ้าของโครงการไม่อยู่ในเกม

## 4. แนวทางที่พิจารณา

| แนวทาง | ลักษณะ | ข้อแลกเปลี่ยน |
|---|---|---|
| ก. ทีละฤดู กดเดินเอง | ปีละ 3 จังหวะตามปฏิทินอีสาน ผู้เล่นกดไปต่อ | อ่านทัน เหมาะมือถือ ต่างจากต้นแบบ ตรวจเนื้อหาง่าย แต่ไม่มีความรู้สึกเวลาไหล |
| ข. เวลาเดินเอง | ปีละ 40–60 วินาที เร่ง/หยุดได้ | รู้สึกชีวิตไหล แต่ใกล้ต้นแบบมาก ซับซ้อน ผู้เล่นอ่านไม่ทัน |
| ค. นิยายแตกแขนง | บทตายตัวตามช่วงวัย | เขียนลึกได้ แต่ขยายไม่ถึง 20 จังหวัด เล่นซ้ำไม่สนุก |

เจ้าของโครงการเลือก **ก.** เหตุผล: อ่านทัน เป็นเอกลักษณ์ของตัวเอง ผูกกับฤดูกาลอีสานได้

## 5. การออกแบบ

### 5.1 เริ่มเกม

ผู้เล่นตั้งค่า:
- ชื่อ, เพศ (ชาย/หญิง — มีผลกับเกณฑ์ทหาร บวช และเหตุการณ์บางอย่าง)
- ปีเกิด 1970–2008 (ค่าเริ่มต้น 1997)
- จังหวัดเกิด: เลือกเองหรือสุ่ม แสดงเฉพาะจังหวัดที่มีอยู่จริงในปีเกิด (เช่น 1970 ยังไม่มียโสธร มุกดาหาร หนองบัวลำภู อำนาจเจริญ บึงกาฬ) ถ้าจังหวัดตั้งขึ้นภายหลังขณะผู้เล่นอยู่ในพื้นที่นั้น เกมแจ้งเป็นเหตุการณ์และเปลี่ยนชื่อจังหวัดที่อยู่
- ถิ่น: ชนบท / ในเมือง
- ฐานะครอบครัว: ยากจน / พอมีพอกิน / มีฐานะ — เลือกเองหรือสุ่มถ่วงน้ำหนักด้วยอัตราความยากจนจริงของภาคอีสานในปีเกิด
- นิสัย 3 แกน ค่า 0–100 ตั้งด้วยแถบเลื่อน หรือกดสุ่ม:
  - ยึดติด ↔ ปล่อยวาง
  - ใจสู้ ↔ ท้อง่าย
  - ชอบเข้าสังคม ↔ เก็บตัว
- หรือกดเลือกเส้นทางสำเร็จรูป (ดู 5.8)

### 5.2 จังหวะเวลา

- อายุ 0–6: ปีละ 1 ตา (ผู้ใหญ่ตัดสินใจแทน แสดงเหตุการณ์ยุคนั้นและชีวิตในบ้าน)
- อายุ 7 ขึ้นไป: ปีละ 3 ตา ตามฤดูอีสาน
  - **หน้าแล้ง** ม.ค.–เม.ย. (บุญข้าวจี่ บุญผะเหวด สงกรานต์ ปิดเทอมใหญ่ คนกลับบ้าน)
  - **หน้านา** พ.ค.–ก.ย. (บุญบั้งไฟ ไถ ดำนา เปิดเทอม เข้าพรรษา)
  - **หน้าเกี่ยว** ต.ค.–ธ.ค. (ออกพรรษา ไหลเรือไฟ เกี่ยวข้าว บุญกฐิน ปีใหม่)
- เหตุการณ์จริงที่รู้เดือน ลงฤดูตามเดือน ที่รู้แค่ปี ลงหน้าแล้งของปีนั้น
- ปุ่ม "ข้ามไปเรื่องสำคัญถัดไป": เดินต่อเองจนเจอตาที่ต้องตัดสินใจหรือเหตุการณ์ใหญ่ ตาที่ข้ามยังคำนวณผลตามปกติและเก็บลงบันทึกชีวิต

### 5.3 หนึ่งตา มีอะไรบ้าง

เรียงจากบนลงล่าง:
1. หัวตา: พ.ศ. (ค.ศ.), อายุ, ฤดู, ที่อยู่ปัจจุบัน, สถานะชีวิต (เช่น นักเรียน ม.2, คนงานโรงงาน)
2. เหตุการณ์โลก 0–2 ใบ: เรื่องจริงของปีและฤดูนั้น กรองตามที่อยู่ (จังหวัด > ทั้งอีสาน > ทั้งประเทศ) มีลิงก์ "ที่มา"
3. เรื่องส่วนตัว 0–1 ใบ: สุ่มจากคลังตามเงื่อนไข (อายุ ยุค สถานะ ที่อยู่ นิสัย ธงเรื่องราว)
4. ทางเลือก ถ้ามี: 2–4 ปุ่ม
5. ผลลัพธ์: ค่าที่เปลี่ยน แสดงเป็นตัวเลข +/−
6. ปุ่ม "ไปต่อ"

ต้นปี (หน้าแล้ง) ตั้งแต่อายุ 7 มีคำถาม "ปีนี้เอาจังได๋" ให้เลือกสิ่งที่ทุ่มเทหนึ่งอย่าง ตัวเลือกเปลี่ยนตามวัยและสถานะ เช่น ตั้งใจเรียน / ช่วยงานบ้าน / เล่นกับหมู่ / หาเงิน / ดูแลพ่อแม่ ส่งผลต่อค่าสถานะทั้งปี

### 5.4 ค่าสถานะ

- สุขภาพ, ความสุข, ความรู้, ความสัมพันธ์: 0–100
- เงิน: จำนวนบาทจริงตามค่าเงินของปีนั้น ติดลบได้ (เป็นหนี้) รายได้และรายจ่ายต่อฤดูมาจากตารางค่าแรง ราคาข้าว ค่าครองชีพจริงตามปี
- ภาวะชั่วคราว: ป้ายที่ติดตัวช่วงหนึ่งและถ่วงค่าสถานะทุกตา เช่น ใจสลาย, คิดถึงบ้าน, เป็นหนี้, ป่วยเรื้อรัง แต่ละป้ายมีจำนวนตาที่เหลือ

### 5.5 นิสัยกับแรงกระแทก

ทุกผลของเหตุการณ์ระบุได้ว่า "ถูกคูณด้วยนิสัยแกนไหน" สูตร: `ผลจริง = ผลพื้นฐาน × (0.5 + ค่านิสัย/100)` (ช่วง 0.5–1.5 เท่า) และจำนวนตาของภาวะชั่วคราวใช้ตัวคูณเดียวกัน

ตัวอย่างอกหัก: ความสุขพื้นฐาน −20 ใจสลาย 4 ตา
- ยึดติด 90: ความสุข −28 ใจสลาย 6 ตา และเปิดทางเลือกเพิ่ม (กินเหล้า / โหมงาน / กลับบ้านหาแม่ / บวช)
- ยึดติด 10: ความสุข −12 ใจสลาย 2 ตา

นิสัยขยับได้ช้าๆ จากเหตุการณ์และทางเลือก (เช่น บวชแล้วยึดติดลดลง)

### 5.6 เส้นทางชีวิต (จุดตัดสินใจหลัก)

ตัวเลือกแต่ละจุดขึ้นกับยุค ฐานะ เพศ ที่อยู่ และค่าสถานะ ตัวเลือกที่ยุคนั้นยังไม่มีจริงจะไม่แสดง (เช่น กยศ. ก่อน 1996, โรงเรียนขยายโอกาสก่อน 1990, ไปเกาหลีก่อน 2004)

| ช่วง | ทางเลือกหลัก |
|---|---|
| เข้า ป.1 | โรงเรียนใกล้บ้าน / โรงเรียนในเมืองหรือเอกชน (ต้องมีเงินหรือญาติ) |
| ระหว่างประถม–มัธยม | ย้ายไปเรียนต่างอำเภอหรือต่างจังหวัด อยู่กับญาติหรือหอ / ย้ายกลับบ้าน |
| จบภาคบังคับ | เรียนต่อ / บวชเรียน / ออกมาทำนา / เข้ากรุงเทพฯ หางาน |
| จบ ม.3 | ม.ปลายสายสามัญ / ปวช. / ทำงาน |
| จบ ม.6 | มหาวิทยาลัย (เฉพาะแห่งที่ตั้งแล้วในปีนั้น สอบติดขึ้นกับความรู้และโชค) / ปวส. / ทำงาน / ไปต่างประเทศ |
| อายุ 21 (ชาย) | เกณฑ์ทหาร: จับใบดำใบแดง / สมัคร / ผ่อนผันถ้ายังเรียน |
| วัยทำงาน | ทำนาที่บ้าน / โรงงาน / ก่อสร้าง / ขับรถ / สอบราชการ-ครู / งานออฟฟิศ / ค้าขาย / ไปต่างประเทศตามยุค (ตะวันออกกลาง ไต้หวัน เกาหลี อิสราเอล เก็บเบอร์รี) / กลับบ้าน |
| ความรัก | ชอบพอ / คบ / อกหัก / แต่ง (สินสอด) / มีลูก / ฝากลูกไว้กับตายาย / เลิกรา |
| ครอบครัว | ส่งเงินกลับบ้าน / ดูแลพ่อแม่ป่วย / งานศพ / มรดกที่นา |
| สุขภาพ | กินปลาดิบ (เสี่ยงพยาธิใบไม้ตับ) / เหล้า / ขี่มอเตอร์ไซค์ไม่ใส่หมวก / ตรวจสุขภาพ |

การย้ายที่อยู่เปลี่ยนเหตุการณ์โลกที่เห็น (อยู่กรุงเทพฯ เห็นเหตุการณ์ระดับประเทศ และเหตุการณ์ใหญ่ของจังหวัดบ้านเกิดในรูป "ข่าวจากบ้าน")

### 5.7 ความตายและฉากจบ

- ทุกปีมีโอกาสเสียชีวิตตามช่วงอายุและยุค (ตารางชีพจริง) ปรับด้วยสุขภาพและภาวะชั่วคราว เหตุการณ์บางอย่างเสี่ยงตายทันที
- ประวัติศาสตร์จริงมีถึงปี 2026 ปีหลังจากนั้นติดป้าย "อนาคต (สมมติ)" ใช้เฉพาะเรื่องส่วนตัว ค่าเงินและค่าแรงคงที่ที่ค่าปีล่าสุด ไม่มีเหตุการณ์โลก
- ฉากจบ: สรุปชีวิตเป็นเส้นเวลา (ที่อยู่ การเรียน งาน ความรัก เหตุการณ์ใหญ่ที่ผ่าน) เทียบกับสถิติจริงของคนอีสานรุ่นเดียวกัน (เช่น สัดส่วนคนเรียนถึง ป.ตรี) ปุ่มคัดลอกข้อความสรุป ปุ่มเกิดใหม่
- ชีวิตที่จบแล้วเก็บเป็นรายการสั้นๆ ในเครื่อง ดูย้อนได้ ลบได้

### 5.8 เส้นทางสำเร็จรูป "เด็กโพนสวรรค์"

- ตั้งค่าเริ่ม: เกิด 2004, นครพนม, ชนบท, ยากจน
- ที่จุดตัดสินใจ ตัวเลือกที่ตรงกับเส้นทางจริงมีป้ายเล็ก "ทางของต้นเรื่อง" ผู้เล่นเลือกตามหรือฉีกก็ได้:
  ประถมโรงเรียนใกล้บ้าน (โพนสวรรค์) → ย้ายไปเรียนโรงเรียนเอกชนคาทอลิกที่ท่าแร่ สกลนคร → ย้ายกลับมาเรียนโพนสวรรค์จนจบ ม.6 → มหาวิทยาลัยมหาสารคาม → ทำงานกรุงเทพฯ
- เส้นทางสำเร็จรูปใส่ชื่อสถานที่จริงทับชื่อกลางๆ ของตัวเลือกได้ (เช่น "โรงเรียนเอกชนต่างจังหวัด" แสดงเป็นชื่อโรงเรียนที่ท่าแร่) ชื่อโรงเรียนใช้ตามที่ตรวจสอบได้จากแหล่งข้อมูล
- โครงสร้างรองรับเส้นทางสำเร็จรูปเพิ่มในอนาคต รอบนี้ทำเส้นทางเดียว

### 5.9 ข้อมูล

ไฟล์ JSON แยกจากโค้ดเกม:

| ไฟล์ | เนื้อหา |
|---|---|
| `data/world-events.json` | เหตุการณ์จริง: ปี, เดือนหรือฤดู, ขอบเขต (จังหวัด/ทั้งอีสาน/ทั้งประเทศ), หมวด, หัวข้อ, เนื้อความ, ผลต่อชีวิต (เงื่อนไข + ผลต่อค่าสถานะ ถ้ามี), แหล่งอ้างอิง, ระดับความมั่นใจ, ธง "เนื้อหาหนัก" |
| `data/personal-events.json` | เรื่องส่วนตัว (แต่งขึ้น): เงื่อนไข, น้ำหนักสุ่ม, เนื้อความ, ทางเลือก, ผล, แกนนิสัยที่คูณ |
| `data/decisions.json` | จุดตัดสินใจหลักตาม 5.6 |
| `data/stats.json` | ตารางตามปี: ความยากจน ค่าแรงขั้นต่ำ เงินเดือน ราคาข้าว ค่าครองชีพ อัตราเรียนต่อ ตารางชีพ พร้อมแหล่งอ้างอิงและระดับพื้นที่ |
| `data/places.json` | 20 จังหวัด (ปีตั้ง จังหวัดแม่ เอกลักษณ์) และสถาบันการศึกษา (ปีตั้ง) |
| `data/presets.json` | เส้นทางสำเร็จรูป |

กติกาข้อมูลจริง
- เหตุการณ์โลกเข้าเกมได้เฉพาะที่ความมั่นใจ สูง หรือ กลาง และมีแหล่งอ้างอิงอย่างน้อย 1 ลิงก์ ความมั่นใจต่ำไม่เข้าเกม
- ตัวเลขที่ไม่มีระดับจังหวัด ใช้ระดับภาคหรือประเทศและติดป้ายบอก ปีที่ไม่มีข้อมูลใช้ค่าปีใกล้สุดที่มี และระบุในหน้าแหล่งข้อมูล
- เรื่องส่วนตัวเป็นเรื่องแต่ง ไม่อ้างเป็นข้อเท็จจริง แต่ต้องสมจริงตามยุค (ไม่มีมือถือในปี 1985)
- เหตุการณ์หนัก (ความรุนแรง การเมือง ภัยพิบัติมีผู้เสียชีวิต): เขียนสั้น เป็นกลาง ไม่บรรยายภาพ ผู้เล่นเปิดปิด "ซ่อนเนื้อหาหนัก" ได้ เมื่อซ่อน เหตุการณ์นั้นไม่แสดง
- มีหน้า "แหล่งข้อมูล" รวมทุกรายการและข้อจำกัดของข้อมูล

ปริมาณเนื้อหารอบแรก: เหตุการณ์โลกราว 180–250 รายการ (จากงานค้นข้อมูล), เรื่องส่วนตัวอย่างน้อย 120 รายการกระจายทุกช่วงวัยและยุค, จุดตัดสินใจหลักราว 25 จุด

ภาษา: ไทยกลางเป็นหลัก แทรกคำอีสานในบทพูดและชื่อปุ่มบางจุด เฉพาะคำที่ตรวจสอบความหมายได้

### 5.10 โครงสร้างโค้ด

- `engine/`: ตัวเกมล้วน ไม่แตะหน้าจอ รับสถานะ + ตัวสุ่มที่ตั้งเมล็ดได้ คืนสถานะใหม่ (ตัวประเมินเงื่อนไข, ตัวใช้ผล + ตัวคูณนิสัย, ตัวเลือกเหตุการณ์, การเงิน, ความตาย)
- `ui/`: วาดหน้าจอจากสถานะ รับการกด
- `data/`: JSON ตาม 5.9
- บันทึกอัตโนมัติทุกตาลง localStorage
- ตรวจสอบ: สคริปต์เดียวรันด้วย Node (1) ตรวจรูปแบบข้อมูลทุกไฟล์ และเหตุการณ์โลกทุกรายการมีแหล่งอ้างอิง (2) จำลอง 1,000 ชีวิตด้วยเมล็ดสุ่มคงที่ ยืนยันว่าไม่ล่ม ค่าสถานะอยู่ในช่วง ทุกชีวิตจบได้ ทุกจุดตัดสินใจหลักถูกเจออย่างน้อยหนึ่งครั้ง

### 5.11 หน้าตา

ทำหน้าตัวอย่าง 3 แนวให้เจ้าของโครงการเลือก (หน้าเริ่มเกม + หน้าหนึ่งตา ข้อมูลสมมติ) แล้วสร้างเกมจริงด้วยแนวที่เลือกแนวเดียว ทั้งสามเป็นธีมสว่าง:
1. **สมุดบันทึกบ้านนา**: กระดาษ ลายมือ ลายผ้าขาวม้า โทนดิน เน้นอ่านเหมือนไดอารี่
2. **ครามมัดหมี่**: การ์ดเรียบ สะอาด ลายเรขาคณิตมัดหมี่ สีครามบนพื้นขาว เน้นมือถือ
3. **แถบชีวิตตามฤดู**: เส้นเวลาชีวิตเป็นแถบสีตามฤดู (แล้ง/นา/เกี่ยว) เด่นกลางจอ ค่าสถานะแบบแผงควบคุม

## 6. การตัดสินใจของผู้ออกแบบ (เจ้าของโครงการยังไม่ได้ยืนยันทีละข้อ)

- ช่วงปีเกิด 1970–2008
- อายุ 0–6 ปีละ 1 ตา
- ค่าสถานะ 4 ตัว + เงินเป็นบาทจริง
- นิสัย 3 แกน และสูตรตัวคูณ 0.5–1.5
- คำถามต้นปี "ปีนี้เอาจังได๋"
- หลังปี 2026 เป็น "อนาคต (สมมติ)"
- ไม่มีคนเกิดพร้อมกันให้เทียบ ใช้เทียบกับสถิติรุ่นเดียวกันตอนจบแทน
- ไม่มีการ์ดแชร์รูปภาพ เสียง และภาพวาดในรอบนี้
- เส้นทางสำเร็จรูปไม่ใส่วันเกิดเต็มและชื่อหมู่บ้าน
- ชื่อเกมชั่วคราว "เกิดอีสาน"

## 7. สิ่งที่ปล่อยให้ผู้สร้างตัดสินใจ

- ชื่อไฟล์และฟังก์ชันภายใน `engine/` และ `ui/`
- ค่าตัวเลขสมดุลเกม (ผลพื้นฐานของแต่ละเหตุการณ์ น้ำหนักสุ่ม) ตราบที่ผ่านการจำลอง 1,000 ชีวิตและชีวิตเฉลี่ยไม่ดีหรือร้ายเกินจริง
- ถ้อยคำของเรื่องส่วนตัว ภายใต้กติกาข้อ 2 และ 5.9
- รายละเอียด CSS ภายในแนวหน้าตาที่ถูกเลือก

## 8. ลำดับงานและการตรวจ

- เจ้าของโครงการติดต่อได้ตลอดงาน เป็นคนเลือกแนวหน้าตาจากหน้าตัวอย่าง 3 แนว งาน `engine/` และ `data/` เริ่มได้ก่อนเลือกหน้าตา งาน `ui/` รอผลเลือก
- ข้อ 6 ถือเป็นข้อยุติเมื่อเอกสารนี้ได้รับอนุมัติ
- งานค้นข้อมูลอยู่ในโฟลเดอร์ `research/` (Markdown) ทุกรายการมีแหล่งอ้างอิง ระดับความมั่นใจ และวันที่ละเอียดเท่าที่แหล่งให้ การแปลงเป็น JSON เป็นส่วนหนึ่งของงานสร้าง
- ถ้าตารางสถิติขาดทั้งตาราง (ผู้ออกแบบตัดสินใจ):
  - ใช้ข้อมูลระดับประเทศที่มีแหล่งอ้างอิงแทน และติดป้ายระดับพื้นที่
  - ถ้าไม่มีแหล่งใดเลย กลไกนั้นใช้ค่าสมมติของเกม ระบุในหน้าแหล่งข้อมูลว่า "ค่าประมาณของเกม ไม่ใช่สถิติ" และห้ามแสดงตัวเลขนั้นต่อผู้เล่นในฐานะข้อเท็จจริง
  - ห้ามค้นเพิ่มแล้วใส่ตัวเลขที่ไม่มีลิงก์แหล่งที่เปิดได้
- การตรวจเนื้อหาก่อนปล่อย: เจ้าของโครงการ (คนนครพนม) ตรวจรายการคำอีสานที่ใช้ และข้อความของเหตุการณ์หนักทุกรายการ ผู้สร้างรวมสองรายการนี้เป็นไฟล์อ่านง่ายให้ตรวจ คำอีสานใช้เท่าที่อยู่ในรายการที่ตรวจแล้วเท่านั้น
- ข้อเท็จจริงของเส้นทาง "เด็กโพนสวรรค์" (ชั้นที่ย้ายไปท่าแร่ ชั้นที่ย้ายกลับ ลักษณะงานที่กรุงเทพฯ) เจ้าของโครงการเป็นผู้ให้ ถ้ายังไม่ได้ ใช้ป้ายกลางๆ ไปก่อน

## 9. นอกขอบเขตเอกสารนี้

- การนำขึ้นเว็บจริง (เลือกที่ฝากและชื่อโดเมน) ตัดสินใจหลังเกมเล่นได้
