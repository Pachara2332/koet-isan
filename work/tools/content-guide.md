# คู่มือเขียนเนื้อหาเกม "เกิดอีสาน"

เกมจำลองชีวิตคนอีสาน เล่นทีละฤดู ผู้เล่นกดเดินเอง ปล่อยให้คนทั่วไปเล่น
หลักใหญ่จากเจ้าของเกม: **ผู้เล่นต้องเลือกเองได้ อะไรจะตามมาก็เพราะการกระทำของตน** และ **ชีวิตต้องมีหลากหลายเส้นทาง หลากหลายจุดเปลี่ยน**

ตัวเกมอยู่ที่ `work/ki-preview/` เป็นเว็บล้วน (classic script ไม่มี build) ข้อมูลอยู่ใน `data/*.js`

## ไฟล์เนื้อหาใหม่

แต่ละชุดเขียนลงไฟล์ของตัวเองไฟล์เดียว ห้ามแก้ไฟล์อื่น รูปแบบ:

```js
globalThis.KI = globalThis.KI || {}; KI.data = KI.data || {};
KI.data.decisions.push(...[
  { ... },
  { ... }
]);
KI.data.personalEvents.push(...[
  { ... }
]);
Object.assign(KI.data.conditions, {
  "id": { ... }
});
```

- ใช้เฉพาะส่วนที่ต้องใช้ ไฟล์ปฏิกิริยาต่อเหตุการณ์จริงใช้ `KI.data.decisions.unshift(...[...])` แทน `push` เพื่อให้มาก่อน
- **ห้ามมี comment ในไฟล์เด็ดขาด** (กฎเจ้าของโปรเจกต์)
- JSON ล้วนในวงเล็บ ใช้ double quote

## จังหวะเวลา

- อายุ = ปีปัจจุบัน − ปีเกิด (นับแบบปีปฏิทิน)
- อายุ 0–5: ปีละ 1 ตา (`season` เป็น `null`) อายุ 6 ขึ้นไป: ปีละ 3 ตา
- `season`: `0` หน้าแล้ง ม.ค.–เม.ย. · `1` หน้านา พ.ค.–ก.ย. · `2` หน้าเกี่ยว ต.ค.–ธ.ค.
- เข้า ป.1 อายุ 6 จบ ป.6 อายุ 12 จบ ม.3 อายุ 15 จบ ม.6 อายุ 18 ปริญญาตรี 4 ปี
- `cooldown`: `"once"` (หรือไม่ใส่) = เกิดครั้งเดียวในชีวิต, ตัวเลข = จำนวนตาก่อนเกิดซ้ำได้ (12 ≈ 4 ปี)

## แต่ละตาเลือกเรื่องยังไง (สำคัญ)

1. การ์ดเหตุการณ์จริง 0–2 ใบ (อ่านอย่างเดียว)
2. ต้นปี (หน้าแล้ง อายุ 6+) การ์ด "ปีนี้เอาจังได๋"
3. **เรื่องราว 1 ใบเท่านั้น**: เกมไล่ `decisions` ตามลำดับ **ใบแรกที่ `when` ผ่านชนะ** ถ้าไม่มี จะสุ่มเรื่องส่วนตัว (`personalEvents`) ด้วยโอกาส 60% ถ่วงด้วย `w`

ดังนั้น `when` ของ decision ต้องแคบ ใส่ช่วงอายุ ปี ฤดู หรือ `chance` เพื่อไม่ให้แย่งตากันจนเรื่องอื่นไม่ได้เกิด เรื่องที่เกิดซ้ำได้ส่วนใหญ่ควรเป็น personal event ที่มี choices

## โครงสร้าง

Decision (จุดตัดสินใจ ต้องมี choices):
```json
{"id":"job-taxi","title":"ขับแท็กซี่ในกรุงเทพฯ","body":"ข้อความ 1–2 ประโยค","when":{...},"cooldown":12,"major":true,
 "choices":[{"id":"go","label":"ข้อความปุ่ม","text":"ผลที่เล่าหลังเลือก","when":{...},"effects":[...],
   "roll":[{"p":0.6,"text":"...","effects":[...]},{"p":0.4,"text":"...","effects":[...]}]}]}
```
Personal event: เหมือนกัน แต่มี `"w":10` (น้ำหนักสุ่ม) และจะมี `choices` หรือแค่ `effects` ก็ได้ ไม่มี `major`

- `roll` (ไม่บังคับ): สุ่มผลเพิ่มหลังเลือก ผลรวม p ≤ 1 ใช้กับเรื่องที่ผลขึ้นกับคนอื่นหรือโชค
- `choice.when`: ซ่อนตัวเลือกถ้าไม่ผ่าน (เช่น ต้องมีเงิน หรือจบ ป.ตรี)
- `heavy: true` สำหรับเรื่องความรุนแรง/ความตาย ผู้เล่นซ่อนได้

## เงื่อนไข `when`

ทุก key ต้องผ่านพร้อมกัน ช่วงตัวเลขเขียน `[ต่ำ, สูง]`:
- `age` `[a,b]` · `year` `[a,b]` (ค.ศ.) · `season` `0|1|2` หรือ `[a,b]`
- `sex` `"m"|"f"` · `wealth` `"poor"|"mid"|"rich"` (ฐานะตอนเกิด)
- `role` ค่าเดียวหรือ array ของ role (ดูด้านล่าง)
- `loc` `"isan"|"bangkok"|"abroad"` · `setting` `"rural"|"urban"` · `province` id จังหวัดที่อยู่ตอนนี้ · `homeProvince` id จังหวัดบ้านเกิด
- `edu` `{"in":["school","voc","hvoc","uni","novice"],"grade":[a,b],"top":["none","p6","m3","m6","pvc","pvs","ba"]}`
- `flag` `{"ชื่อ":true}` หรือ `{"ชื่อ":ค่า}` (ตรงทุกตัว) · `noFlag` `["ชื่อ"]` (ต้องไม่มีสักตัว)
- `trait` `{"attach":[a,b],"grit":[a,b],"social":[a,b]}` · `stat` `{"health":[a,b],"happy":..,"know":..,"bond":..}`
- `money` `[a,b]` (บาท) · `cond` `["id"]` (มีภาวะใดภาวะหนึ่ง) · `noCond` `["id"]`
- `partnerYears` `[a,b]` · `marriedYears` `[a,b]` · `childAge` `[a,b]`
- `any` `[{...},{...}]` ผ่านข้อใดข้อหนึ่ง · `chance` `0.3` สุ่มผ่าน (ใส่ท้ายสุด)
- `preset` `"phon-sawan"`

## ผล `effects`

- `{"stat":"happy","d":-5}` สุขภาพ/ความสุข/ความรู้/ความสัมพันธ์ (`health|happy|know|bond`) ช่วง 0–100
- `{"trait":"attach","d":-3}` นิสัยขยับ
- `{"money":-20,"unit":"wageDay"}` เงินเป็นจำนวนวันค่าแรงขั้นต่ำของปีนั้น (**ใช้หน่วยนี้เสมอ** ราคาจะถูกตามยุค) หรือ `{"money":-500}` บาทตรงๆ
- `{"cond":"heartbroken","turns":4}` ใส่ภาวะชั่วคราว · `{"uncond":"sick"}` เอาออก
- `{"flag":"ชื่อ","v":true}` (ไม่ใส่ v = true)
- `{"role":"factory"}` เปลี่ยนอาชีพ
- `{"move":{"kind":"bangkok"}}` · `{"move":{"kind":"abroad","country":"ไต้หวัน"}}` · `{"move":{"kind":"isan","province":"khon-kaen","setting":"urban"}}` · `{"move":"home"}` กลับบ้านเกิด
- `{"edu":{"in":"uni","grade":1,"place":"ชื่อสถานศึกษา"}}`
- `{"die":"road","p":0.1}` โอกาสตาย สาเหตุที่มี: `road` `drown` `accident` `work` `liver` `illness` `old-age`
- `{"pin":"ข้อความ"}` หมุดหมายบนเส้นทางชีวิต (ใช้กับจุดเปลี่ยนใหญ่เท่านั้น)
- ใส่ `"by":"attach"` (หรือ `"-attach"` `"grit"` `"-grit"` `"social"` `"-social"`) เพื่อคูณผลด้วยนิสัย 0.5–1.5 เท่า เช่น เจ็บใจคูณ `attach` ใจสู้ช่วยลดผลร้ายใช้ `-grit`

## กติกาการเขียน

1. ภาษาไทยกลาง อ่านง่าย 1–2 ประโยคต่อ body แทรกคำอีสานได้เฉพาะคำที่รู้ความหมายแน่นอน (เช่น บ่, เฮ็ด, แซบ, ข้าวเหนียว, ปลาแดก)
2. **ทุกทางเลือกมีข้อแลก** ไม่มีตัวเลือกที่ดีกว่าทุกด้าน ผลที่ตามมาต้องสมเหตุสมผลกับสิ่งที่เลือก
3. ผลร้ายแรงต้องมาจากทางเลือกของผู้เล่น (ตั้ง flag ตอนเลือก แล้วให้ผลตามมาภายหลัง) ไม่ใช่ลงโทษสุ่มลอยๆ
4. ตรงยุค: ใช้ `year` กั้น เช่น มือถือไม่ก่อน ~2000, Facebook ~2009+, TikTok ~2019+, ไปเกาหลีระบบ EPS 2004+, ไลฟ์ขายของ ~2018+, 30 บาท 2002+, กยศ. 1996+
5. ห้ามแต่งข้อเท็จจริงทางประวัติศาสตร์ ถ้าอ้างเหตุการณ์จริง ต้องตรงกับปี ฤดู จังหวัด ใน `data/world-events.js` หรือเป็นเรื่องที่รู้กันทั่วไปแน่นอน ตัวเลขเงินในเรื่องเป็นค่าเกม ไม่ต้องอ้างอิง แต่ต้องไม่อ้างว่าเป็นสถิติ
6. ไม่ล้อเลียน ไม่เหมารวม ไม่ขายความจน ไม่เลือกข้างการเมือง ไม่บรรยายความรุนแรง
7. เจ็บทางใจ (เสียคนรัก ผิดหวัง) ใส่ `"by":"attach"`
8. ใช้ effect ขนาดเล็กเป็นหลัก (±2 ถึง ±8) เรื่องใหญ่จริงถึง ±20

## ตรวจงาน

```bash
node work/tools/check.js 60 <prefix-ของชุด>
```
ต้องขึ้น `OK` ไม่มี ERRORS และเรื่องในชุดตัวเองควรถูกพบเกือบทั้งหมด (`items never seen` น้อย) ถ้าเจอ error ที่อยู่ในไฟล์ของชุดอื่น (อาจกำลังเขียนอยู่) รอแล้วรันใหม่ ไม่ต้องแก้ไฟล์คนอื่น

## เพิ่มทางเลือกให้เรื่องที่มีอยู่แล้ว

ไฟล์ `data/more-choices-*.js` เพิ่ม choices ให้เรื่องเดิมโดยไม่แก้ไฟล์ต้นทาง ใส่ใน object `add` โดย key = id ของเรื่อง ค่า = array ของ choice ใหม่ (รูปแบบเดียวกับ choice ปกติ id ห้ามซ้ำกับ choice เดิมของเรื่องนั้น):

```js
  const add = {
    "raw-fish": [{"id":"jaew","label":"...","text":"...","effects":[...]}],
    "sea-dam-na": [...]
  };
```

## ตัวนับพฤติกรรม

- ผล `{"inc":"naughty"}` เพิ่มตัวนับชื่อ naughty ทีละ 1 (`{"inc":"naughty","d":-2}` ลดได้ ไม่ต่ำกว่า 0)
- เงื่อนไข `{"counter":{"naughty":[3,99]}}` ตัวนับที่ไม่เคยตั้งนับเป็น 0
- ไฟล์ `data/more-behavior.js` ใส่ผลเพิ่มให้ทางเลือกที่มีอยู่แล้ว โดยไม่แก้ไฟล์ต้นทาง: key ใน object `tag` = `"idเรื่อง/idทางเลือก"` ค่า = array ของ effect ที่จะต่อท้าย

## สถานะครอบครัวและการจำกัดเรื่องเดิม

- flag ที่ระบบตั้งให้ทุกตา: `fatherAlive` `motherAlive` `parentsAlive` (พ่อหรือแม่ยังมีชีวิตอย่างน้อย 1 คน) `grandparentsAlive` `hasSiblings` `kids` (จำนวนลูก) และ `status` = ฐานะครัวเรือนตอนนี้ (`"poor"|"mid"|"rich"|"wealthy"` คิดจากเงิน ทรัพย์สิน และฐานะพ่อแม่ถ้ายังอยู่บ้านเดียวกัน เทียบค่าแรงของปีนั้น) ใช้ใน when เช่น `{"flag":{"parentsAlive":true}}` หรือ `{"flag":{"status":"rich"}}`
- `movedOut` (ตั้งเองได้) = แยกออกจากบ้านพ่อแม่แล้ว ฐานะพ่อแม่จะไม่ถูกนับรวม
- พระ (`role: "monk"`) จะเห็นเฉพาะเรื่องที่ `when.role` มี `"monk"` เท่านั้น เรื่องของฆราวาสทั้งหมดถูกซ่อนอัตโนมัติ
- ไฟล์ `data/more-life.js` มี object `gate` ใช้เพิ่มเงื่อนไขให้เรื่องเดิม (รวม `KI.data.focus`) โดยไม่แก้ไฟล์ต้นทาง: key = id เรื่อง ค่า = เงื่อนไขที่จะรวมเข้า `when` (flag รวมกันได้)

## ระดับธุรกิจ

ตัวนับ `biz` (0–6) คือขนาดกิจการของผู้เล่น ระบบเพิ่มรายได้ให้ทุกฤดูตามระดับ (ต่อฤดู เป็นวันค่าแรง): 1=25 แผงลอย, 2=70 ร้านเล็ก, 3=180 ร้านขาประจำ, 4=450 หลายสาขา, 5=1100 บริษัทในจังหวัด, 6=2500 เจ้าสัวท้องถิ่น ใช้ `{"inc":"biz"}` เมื่อกิจการโตขึ้น `{"inc":"biz","d":-1}` เมื่อหดลง และ `{"counter":{"biz":[a,b]}}` เป็นเงื่อนไข ฐานะครัวเรือน (`status`) จะขยับเองตามเงินที่ได้

## พรสวรรค์และทักษะ

- ทุกคนมี `talents.learn` (0.55–1.45) คูณกับความรู้ที่ได้เพิ่ม (เฉพาะ `know` ที่เป็นบวก) และสุ่มพรสวรรค์ 0–3 ด้าน ระดับ 1–3 จาก: `music sport art math computer gaming chess language cooking craft speech mechanic muaythai farming`
- เงื่อนไข `{"talent":{"music":[1,3]}}` (ไม่มีพรสวรรค์ด้านนั้น = 0 ใช้ `[0,0]` เพื่อหาคนที่ไม่ถนัด) · `{"learn":[1.2,2]}` หัวไว · `{"learn":[0,0.9]}` เรียนรู้ช้า
- ทักษะที่ฝึกใช้ตัวนับ `skill-<ด้าน>` เช่น `{"inc":"skill-music"}` ถ้ามีพรสวรรค์ด้านนั้น ระบบคูณการเพิ่มให้เอง (ระดับ 1 = 1.5 เท่า, 2 = 2 เท่า, 3 = 2.5 เท่า) เงื่อนไข `{"counter":{"skill-music":[5,99]}}`

## อาชีพใหม่ เรียนแพทย์ และฐานะครอบครัว

- role ใหม่ (รายได้ต่อฤดูคิดให้อัตโนมัติ): `doctor nurse engineer developer police lawyer pharmacist accountant banker chef mechanic artist creator rider security housekeeper athlete designer business`
- เรียนแพทย์: `{"edu":{"in":"med","grade":1,"place":"คณะแพทยศาสตร์ ..."}}` เรียน 6 ปี จบได้ `top: "ba"` (ตั้ง flag ของตัวเองไว้เช็คว่าเรียนแพทย์จบ)
- `{"wealth":"poor"|"mid"|"rich"}` เปลี่ยนฐานะบ้านพ่อแม่ (ครอบครัวเดิม) ซึ่งนับรวมในฐานะครัวเรือนถ้ายังอยู่บ้านเดียวกัน เงื่อนไข `{"wealth":"poor"}` คือฐานะบ้านพ่อแม่ตอนนี้ (ฐานะตอนเกิดเก็บแยกไว้)
- คู่รัก/คู่สมรสเป็นเพศตรงข้ามกับผู้เล่นเสมอ เขียนให้สอดคล้อง หรือใช้คำกลางๆ เช่น "คู่ชีวิต" "แฟน"
